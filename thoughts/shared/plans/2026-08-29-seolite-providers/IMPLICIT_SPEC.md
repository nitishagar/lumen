Status: authored 2026-08-29 by the providers plan author (protocol create_plan_generic_v2_5, scale=large).
Inherits the global Implicit Spec **I1–I17** from `thoughts/shared/research/2026-08-29-seolite-greenfield-research.md` (§Implicit Spec) and the locked contract in `thoughts/shared/plans/2026-08-29-seolite/ARCHITECTURE.md` (package table, Provider SPI signatures, payload required fields). ## 1. Inherited invariants → binding on `packages/providers`

| Invariant | Binding for this aspect |
|---|---|
| **I1 Zero-cost defaults** | Every built-in provider is free (no paid API in any default path). BYOK keys are carried in config as env-var **names** only; values are read at call time via an injected env reader, never persisted, never logged. Key absent → a typed **NotConfigured** outcome (ProviderError, code `not_configured`) — never a crash, and never a keyless call to an endpoint whose docs require a key (CrUX: key REQUIRED; PSI: key required for automated use). A config that embeds a secret VALUE is rejected with a config error. |
| **I2 Pluggability at every data boundary** | All vendor/external calls live in this package and only here. All seven names (`google-suggest`, `wikipedia-demand`, `pagespeed`, `crux`, `openpagerank`, `tranco`, `ddg-serp`) are exported and wired into core's registry with a declared capability (keyword / serp / pagespeed / crux / authority). Providers export the canonical name list the core registry uses for its I2 edge (unknown name → explicit error listing available providers). Swapping a provider never changes CLI/MCP surface. |
| **I3 Data honesty** | Every emitted value carries provenance: `source { provider, kind, attribution?, retrievedAt }` (or the flat `provider`/`attribution` fields the locked AuthoritySignal model already requires). `kind` labels: `gray` (google-suggest, ddg-serp), `heuristic` (wikipedia-demand, openpagerank), `community` (tranco), `lab` (PSI/Lighthouse), `field` (CrUX, PSI-embedded CrUX) — requires the additive core enum extension `'gray'` (edge A9). Heuristic/proxy values carry an `estimateLabel` that says what the number actually is (e.g. "demand proxy, not search volume"). Provider failure → field omitted, `null` (CrUX no-data), or `[]` — **never zero-filled**. |
| **I4 Crawl etiquette** | Every outbound request carries a UA that identifies seolite with a contact URL (Wikimedia additionally requires this by policy — edge A3). Each source gets a client-side rate limiter at or under its documented/conservative limit (edges A1–A7). `Retry-After` is honored everywhere it appears. Tranco fetches its list at most once per refresh window (default 7 days). |
| **I8 License & attribution** | The CrUX CC BY 4.0 attribution string is attached to **every** CrUX record (verbatim duty: "The CrUX datasets from Google are licensed under the Creative Commons Attribution 4.0 International license" — research ledger). Tranco attribution attached to every signal ("attribution required" — Tranco). Open PageRank attribution attached conservatively (their docs moved; string attached regardless). Attribution constants are exported so site-docs can render them (display duty sits with site/reports; the strings are owned here). |
| **I9 TDD gate** | Every provider gets contract tests against **injected fetchers** with fixture responses shaped like the real APIs. No test touches the live network. Phase not done until `npm test -w @seolite/providers` green. |
| **I10 Determinism** | Clock, sleep, env, cache, and fetcher are all injected. No test or provider behavior depends on wall-clock time or live network state. TTLs/throttles are exercised with a fake clock. |
| **I12 SSRF safety** | All HTTP goes through the injected core `Fetcher` (SSRF-guarded). This package contains **zero** direct `fetch()` usage — enforced by an automated source-scan test. |
| **I15 Boundary inputs** | Defined behavior for: malformed JSON (→ `parse_error`), malformed/unexpected HTML (→ `parse_error`; layout drift → `parse_error`), CAPTCHA/anomaly pages (→ `blocked`), empty bodies, oversized Tranco CSV (streamed, capped at `maxRows`), domains normalized (lowercase, scheme/path/trailing-dot stripped) before Tranco/OPR lookup. |
| **I16 Privacy / no telemetry** | Package README carries the per-provider "what data leaves the machine" table (seed term → Google/Wikipedia; URL → Google PSI; origin/url → Google CrUX; domain → openpagerank.com; domain list → tranco-list.eu; query → DuckDuckGo). No telemetry; keys never logged; error messages redact `key`/`token` query params (`redactUrl`). |
| **I17 Retry & backoff** | Timeout, bounded retry, exponential backoff + jitter, and Retry-After honoring are owned by the core `Fetcher` (single retry owner — providers never retry, avoiding double-retry). Providers own the **client-side source throttles** (per-source limits are provider knowledge) and map the final outcome to typed, actionable errors with the provider name attached: `not_configured`, `rate_limited` (+ `retryAfterMs`), `blocked`, `upstream_error` (+status), `parse_error`, `timeout`, `stale_cache`. |

## 2. Aspect edges — per-provider limits are REQUIREMENTS (with evidence refs)

All evidence from `2026-08-29-seolite-greenfield-research.md` (§Seam 3 free data source matrix; §Evidence Ledger). Numbers are quoted exactly.

- **A1 — CrUX API v4**: key REQUIRED ("Using the CrUX API requires a Google Cloud API key" — keyless claim REFUTED in audit round 1). Quota verbatim: "limited to 150 queries per minute per Google Cloud project, which is offered without charge"; not increasable by payment. **Requirement: client-side throttle never exceeds 150 qpm; CC BY 4.0 attribution string on every record; `null` record when the API has no data.** (research §Seam 3 matrix row "CrUX API v4"; ledger rows "CrUX API free, 150 qpm…", "CrUX API requires a Google Cloud API key (keyless claim REFUTED)").
- **A2 — Open PageRank**: free key BYOK, **Bearer token auth** (old `API-OPR` header REFUTED in audit — stale docs), **60 req/min** plus a **monthly domain quota** (docs example ~30k/month); docs now at `openpagerank.keywordseverywhere.com/docs`. **Requirement: Bearer header; throttle ≤60 req/min (default 50); monthly quota exhaustion surfaces as a typed rate_limited error with reason `monthly-quota`.** (research §Seam 3 row "Open PageRank"; ledger row "Open PageRank docs stale…").
- **A3 — Wikimedia pageviews + REST**: no auth; "include a meaningful User-Agent header that includes contact information" required; **200 req/min** with compliant UA; **429 + Retry-After** on excess. **Requirement: contact UA on every call; throttle ≤200 req/min (default 60); 429 → typed rate_limited with parsed Retry-After.** (research §Seam 3 row "Wikimedia pageviews + REST"; ledger row "Wikimedia 200 req/min w/ UA w/ contact…").
- **A4 — PageSpeed Insights API v5**: key optional for trial, "needed for automated multiple queries" (BYOK); documented-page limits corroborated at ~25k/day, 240/min (`[R]` — not on the doc page). **Requirement: keyless single (trial) calls allowed; `automated: true` calls without a key → NotConfigured; throttles 60/min keyed, 6/min keyless; lab (`lighthouseResult`) and field (`loadingExperience`) data kept as separate provenance kinds.** (research §Seam 3 row "PageSpeed Insights API v5"; ledger row "PSI API official free; key optional for trial").
- **A5 — Google autocomplete** (`suggestqueries.google.com/complete/search?client=firefox`): none auth, undocumented, **429/CAPTCHA at scale**, ToS **gray**. **Requirement: gray provenance label, aggressive cache (24h), conservative client throttle (30 req/min), 429/CAPTCHA → typed degraded outcome (`rate_limited` / `blocked`), documented as brittle.** (research §Seam 3 row "Google autocomplete"; bounding assumption "gray providers are clearly labeled and cache aggressively").
- **A6 — DuckDuckGo html/lite**: none auth, HTML-only DOM parse, undocumented, **active bot protection, CAPTCHAs commonly reported**, **gray**. **Requirement: gray label, conservative rate limit (6 req/min default), honor 429 + Retry-After, CAPTCHA/anomaly page → typed `blocked`, parse layout drift → typed `parse_error`, brittleness documented, replacement pluggable via SPI/registry (I2).** (research §Seam 3 row "DuckDuckGo html/lite endpoints").
- **A7 — Tranco**: daily list, no auth, **attribution required**. **Requirement: CSV list download + local parse (no per-domain query API in the free tier); refresh at most once per refresh window (default 7 days); staleness disclosed in emitted values; staleness beyond ceiling (14 days) → typed `stale_cache`; attribution on every signal.** (research §Seam 3 row "Tranco").
- **A8 — CrUX attribution duty**: verbatim "The CrUX datasets from Google are licensed under the Creative Commons Attribution 4.0 International license" — attribution + license link owed wherever CrUX data is displayed/redistributed. **Requirement: the exact attribution string is attached to every CrUX record and exported for display.** (research §Seam 5; ledger row "CrUX data CC BY 4.0 attribution duty").
- **A9 — Core model additive deltas (agreed by this spec; P1 owns core TS)**: required by I3 as applied to this package's payloads: (a) `ProvenanceKind` union += `'gray'`; (b) `SerpResult` += optional `source { provider, kind, attribution? }` + `retrievedAt` (locked required fields unchanged); (c) `AuthoritySignal` += optional `retrievedAt`, `estimateLabel` (locked required fields unchanged). All additive, non-breaking, one-line edits; verified by a compile-time test in Phase 0.
- **A10 — Non-goals enforced by evidence**: no provider may be built on Google Programmable Search JSON API (closed to new customers; full API shutdown 2027-01-01 — ledger) or Bing Search API (retired 2025-08-11 — ledger). Brave Search / DataForSEO / serper.dev are PAID/BYOK-later — SPI hooks only, not built-ins (research §Seam 1+3 rows; I1).

Locked BYOK env-var names (defaults; config may override the NAME, never embed a value):
`SEOLITE_PSI_API_KEY`, `SEOLITE_CRUX_API_KEY`, `SEOLITE_OPENPAGERANK_API_KEY`.

Error semantics summary (typed, provider name always attached): key absent → `not_configured`; 429 → `rate_limited` (+`retryAfterMs` from Retry-After); CAPTCHA/bot-block → `blocked`; HTTP 5xx / network after core retries → `upstream_error`; malformed JSON/HTML → `parse_error`; fetcher timeout → `timeout`; stale local list → `stale_cache`; CrUX "no data" → `null` (not an error); Tranco/authority absence → `[]` (never zero-fill).

## 4. Bounding assumptions (conservative defaults, recorded for autonomous mode)

- **BA1** Throttle defaults = documented limit × ~0.8–0.95 safety margin where a documented limit exists; fixed conservative constants where none exists (30/min suggest, 6/min ddg).
- **BA2** Cache TTLs are the defaults in the matrix, configurable per provider via config (e.g. `tranco.refreshDays`); cache is a providers-local `CacheStore` port with an in-memory default — surfaces may inject a file-backed store later (core defines no cache contract).
- **BA3** Tranco: parse the first `maxRows` (default 100,000) rows of the published daily CSV (`download_path` from `GET https://tranco-list.eu/api/lists/date/{date}`); if today's list is unpublished, walk back up to 3 days; serve cached up to 14 days, then `stale_cache`. Domains outside the top-N → omitted (`[]`), never a zero rank.
- **BA4** wikipedia-demand: `en.wikipedia` only in v1; demand = sum of trailing-28-day daily pageviews ending today−2d (data lag); no matching article → `[]` (omitted, I3); output explicitly labeled "demand proxy, not search volume".
- **BA5** pagespeed: keyless trial calls allowed only when `automated` is false (single interactive reports); batch/CI/MCP callers pass `automated: true` and therefore require the key.
- **BA6** NotConfigured is expressed as a typed error (code `not_configured`) under the locked SPI signatures (no result-union change to core); the engine/surface layer catches it and renders "not configured" — that catch IS the I1 "skip with explicit result". CrUX `null` is reserved for "API has no record" so the two meanings never collide.
- **BA7** `fcn` in the locked PageSpeedReport model is interpreted as First Contentful Paint (PSI audit `first-contentful-paint`).
- **BA8** Open PageRank request shape: GET `https://openpagerank.com/api/v1.0/getPageRank?domains[i]=…` (≤100 per request) with `Authorization: Bearer <key>`; response per-domain fields parsed as `page_rank_decimal` (fallback `page_rank_integer`) and `rank`. Fixtures encode this documented shape; parsing is tolerant to field fallback.
- **BA9** ddg-serp is Node-only (cheerio per ARCHITECTURE "Node-side only"; the Worker parses no HTML per I6): a `createWorkerSafeProviders(...)` export wires all providers except `ddg-serp`.
- **BA10** All fixtures are static, hand-written from the documented/observed API shapes recorded in research — no test fetches anything live, ever.
- **BA11** Unicode/IDN domains are lowercased and scheme/path-stripped before Tranco/OPR lookup; full IDNA punycode conversion is out of scope for v1 (documented limitation, consistent with research I15 bounding).
- **BA12** Core opts types (`IdeasOpts`, `SearchOpts`, report/crux/authority opts) are assumed minimal (`lang?`, `limit?`, `strategy?`, `formFactor?`, `automated?`, `scope?`); if P1 ships narrower shapes, the adaptation is confined to one file (`src/opts-bridge.ts`) in this package.
