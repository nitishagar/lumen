Status: authored 2026-08-29 by the providers plan author (protocol create_plan_generic_v2_5, scale=large); reworked after adversarial validation (PLAN_VALIDATION.md).
Inherits the global Implicit Spec **I1–I17** from `thoughts/shared/research/2026-08-29-seolite-greenfield-research.md` (§Implicit Spec), the locked contract in `thoughts/shared/plans/2026-08-29-seolite/ARCHITECTURE.md` (package table, Provider SPI signatures, payload required fields), and `thoughts/shared/plans/2026-08-29-seolite/RECONCILIATION.md` (**R1–R10 authoritative on conflict** — in particular R5 BYOK env-var names and R7 worker safety). ## 1. Inherited invariants → binding on `packages/providers`

| Invariant | Binding for this aspect |
|---|---|
| **I1 Zero-cost defaults** | Every built-in provider is free (no paid API in any default path). BYOK keys are carried in config as env-var **names** only (R5 scheme `SEOLITE_<PROVIDER>_KEY`); values are read at call time via an injected env reader, never persisted, never logged. Key absent → a typed **NotConfigured** outcome (ProviderError, code `not_configured`) — never a crash, and never a keyless call to an endpoint whose docs require a key (CrUX: key REQUIRED; PSI: key required when `automated: true`; keyless PSI trial calls stay allowed when `automated !== true`). A config that embeds a secret VALUE is rejected with a config error. |
| **I2 Pluggability at every data boundary** | All vendor/external calls live in this package and only here. All seven names (`google-suggest`, `wikipedia-demand`, `pagespeed`, `crux`, `openpagerank`, `tranco`, `ddg-serp`) are exported and wired into core's registry with a declared capability (keyword / serp / pagespeed / crux / authority). Providers export the canonical name list the core registry uses for its I2 edge (unknown name → explicit error listing available providers). Swapping a provider never changes CLI/MCP surface. |
| **I3 Data honesty** | Every emitted value carries provenance: `source { provider, kind, attribution?, retrievedAt }` (or the flat `provider`/`attribution` fields the locked AuthoritySignal model already requires). `kind` labels: `gray` (google-suggest, ddg-serp), `heuristic` (wikipedia-demand, openpagerank), `community` (tranco), `lab` (PSI/Lighthouse), `field` (CrUX, PSI-embedded CrUX) — requires the additive core enum extension `'gray'` (edge A9). Every `heuristic`/`gray` value also carries an `estimateLabel` that says what the value actually is (e.g. "demand proxy, not search volume"; "undocumented autocomplete endpoint"). Provider failure → field omitted, `null` (CrUX no-data), `[]`, or the per-domain signal skipped (OPR non-found domains) — **never zero-filled, never `value: undefined`**. |
| **I4 Crawl etiquette** | Every outbound request carries a UA that identifies seolite with a contact URL (Wikimedia additionally requires this by policy — edge A3). Each source is paced client-side at or under its documented/conservative limit using GCRA pacing whose worst-case rolling window (`burst + rate`) is provably ≤ the documented limit (edges A1–A7). `Retry-After` is honored everywhere it appears. Tranco fetches at most one metadata GET + one CSV download per refresh window (default 7 days). |
| **I8 License & attribution** | The **verbatim** CrUX attribution string — "The CrUX datasets from Google are licensed under the Creative Commons Attribution 4.0 International license" (plus the methodology URL) — is attached to **every** CrUX record (research ledger, verbatim duty). Tranco attribution attached to every signal ("attribution required" — Tranco). Open PageRank attribution attached conservatively (their docs moved; string attached regardless). Attribution constants are exported so site-docs can render them (display duty sits with site/reports; the strings are owned here). |
| **I9 TDD gate** | Every provider gets contract tests against **injected fetchers** with fixture responses shaped like the real APIs. No test touches the live network. Phase not done until `npm test -w @seolite/providers` green. |
| **I10 Determinism** | Clock, sleep, env, cache, and fetcher are all injected. No test or provider behavior depends on wall-clock time or live network state. TTLs/pacing are exercised with a fake clock. |
| **I12 SSRF safety** | All HTTP goes through the injected core `Fetcher` (SSRF-guarded). This package contains **zero** direct `fetch()` usage — enforced by an automated source-scan test. |
| **I15 Boundary inputs** | Defined behavior for: malformed JSON (→ `parse_error`, via the shared typed-JSON helper — never misclassified as `upstream_error`), malformed/unexpected HTML (→ `parse_error`; layout drift → `parse_error`), CAPTCHA/anomaly pages (→ `blocked`), HTTP 5xx (→ retryable-class `upstream_error`, distinct from `blocked`), empty bodies, oversized Tranco CSV (streamed, capped at `maxRows`), domains normalized (lowercase, scheme/path/trailing-dot stripped) before Tranco/OPR lookup. |
| **I16 Privacy / no telemetry** | Package README carries the per-provider "what data leaves the machine" table (seed term → Google/Wikipedia; URL → Google PSI; origin/url → Google CrUX; domain → openpagerank.com; domain list → tranco-list.eu; query → DuckDuckGo). No telemetry; keys never logged; error messages redact `key`/`token` query params (`redactUrl`). |
| **I17 Retry & backoff** | Timeout, bounded retry, exponential backoff + jitter, and Retry-After honoring are owned by the core `Fetcher` (single retry owner — providers never retry, avoiding double-retry). Providers own the **client-side source pacing** (per-source limits are provider knowledge) and map the final outcome to typed, actionable errors with the provider name attached: `not_configured`, `rate_limited` (+ `retryAfterMs`), `blocked`, `upstream_error` (+status), `parse_error`, `timeout`, `stale_cache`. Timeout classification is TYPE-based (fetch-layer typed errors / `AbortError` / `TimeoutError` names), never message-text sniffing. |

## 2. Aspect edges — per-provider limits are REQUIREMENTS (with evidence refs)

All evidence from `2026-08-29-seolite-greenfield-research.md` (§Seam 3 free data source matrix; §Evidence Ledger). Numbers are quoted exactly.

- **A1 — CrUX API v4**: key REQUIRED ("Using the CrUX API requires a Google Cloud API key" — keyless claim REFUTED in audit round 1). Quota verbatim: "limited to 150 queries per minute per Google Cloud project, which is offered without charge"; not increasable by payment. **Requirement: GCRA pacing with `rate 140/min + burst 10` → worst-case rolling 60 s window exactly 150 = documented limit, never above; verbatim CC BY 4.0 attribution string on every record; `null` record when the API has no data.** (research §Seam 3 matrix row "CrUX API v4"; ledger rows "CrUX API free, 150 qpm…", "CrUX API requires a Google Cloud API key (keyless claim REFUTED)").
- **A2 — Open PageRank**: free key BYOK, **Bearer token auth** (old `API-OPR` header REFUTED in audit — stale docs), **60 req/min** plus a **monthly domain quota** (docs example ~30k/month); docs now at `openpagerank.keywordseverywhere.com/docs`. **Requirement: Bearer header; per-domain requests (the locked SPI `authority(domain, o)` takes ONE domain) paced `rate 50/min + burst 10` → worst-case rolling 60 s window exactly 60 = documented limit; monthly quota exhaustion surfaces as a typed rate_limited error with reason `monthly-quota`; a per-domain non-quota error omits that domain's signals (I3), never emitting `value: undefined`. The documented 100-domain bulk call is a recorded future caller-side optimization, OUT of v1 scope.** (research §Seam 3 row "Open PageRank"; ledger row "Open PageRank docs stale…").
- **A3 — Wikimedia pageviews + REST**: no auth; "include a meaningful User-Agent header that includes contact information" required; **200 req/min** with compliant UA; **429 + Retry-After** on excess. **Requirement: contact UA on every call; pacing `rate 60/min + burst 10` → worst window 70 = 0.35× documented; 429 → typed rate_limited with parsed Retry-After.** (research §Seam 3 row "Wikimedia pageviews + REST"; ledger row "Wikimedia 200 req/min w/ UA w/ contact…").
- **A4 — PageSpeed Insights API v5**: key optional for trial, "needed for automated multiple queries" (BYOK); documented-page limits corroborated at ~25k/day, 240/min (`[R]` — not on the doc page). **Requirement: keyless single (trial) calls allowed when `automated !== true`; `automated: true` without a key → NotConfigured; pacing keyed `rate 60/min + burst 10` (worst 70 = 0.29× documented; rate alone 0.25×) and keyless `rate 6/min + burst 1`; keyed and keyless results cached under SEPARATE cache keys; lab (`lighthouseResult`) and field (`loadingExperience`) data kept as separate provenance kinds.** (research §Seam 3 row "PageSpeed Insights API v5"; ledger row "PSI API official free; key optional for trial").
- **A5 — Google autocomplete** (`suggestqueries.google.com/complete/search?client=firefox`): none auth, undocumented, **429/CAPTCHA at scale**, ToS **gray**. **Requirement: gray provenance label + `estimateLabel` on every idea, aggressive cache (24h), pacing `rate 30/min + burst 5` (worst 35/min), HTTP 429 → typed `rate_limited`, 5xx → `upstream_error`, non-5xx 4xx / HTML body → `blocked` (CAPTCHA), JSON-garbage → `parse_error`, documented as brittle.** (research §Seam 3 row "Google autocomplete"; bounding assumption "gray providers are clearly labeled and cache aggressively").
- **A6 — DuckDuckGo html/lite**: none auth, HTML-only DOM parse, undocumented, **active bot protection, CAPTCHAs commonly reported**, **gray**. **Requirement: gray label, paced rate 6/min (10 s spacing, burst 1 → worst 7/min), honor 429 + Retry-After, 5xx → `upstream_error`, other 4xx / challenge page → typed `blocked`, layout drift → typed `parse_error`, ONE lite-endpoint fallback per call (fires only on drift/challenge from the primary, never on 429/5xx), brittleness documented, replacement pluggable via SPI/registry (I2).** (research §Seam 3 row "DuckDuckGo html/lite endpoints").
- **A7 — Tranco**: daily list, no auth, **attribution required**. **Requirement: CSV list download + local parse (no per-domain query API in the free tier); each refresh = 1 metadata GET + 1 CSV download, at most once per refresh window (default 7 days); if today's list is unpublished walk back ≤3 days; if all 4 dates 404 on first run → typed `upstream_error` (defined outcome); staleness disclosed in emitted values; cached list older than 14 days → typed `stale_cache`; attribution on every signal.** (research §Seam 3 row "Tranco").
- **A8 — CrUX attribution duty**: verbatim "The CrUX datasets from Google are licensed under the Creative Commons Attribution 4.0 International license" — attribution + license link owed wherever CrUX data is displayed/redistributed. **Requirement: that exact string (plus the methodology URL) is attached to every CrUX record and exported for display.** (research §Seam 5; ledger row "CrUX data CC BY 4.0 attribution duty").
- **A9 — Core model additive deltas (agreed by this spec; P1 owns core TS)**: required by I3 as applied to this package's payloads: (a) `ProvenanceKind` union += `'gray'`; (b) `SerpResult` += optional `source { provider, kind, attribution? }` + `retrievedAt` (locked required fields unchanged); (c) `AuthoritySignal` += optional `retrievedAt`, `estimateLabel` (locked required fields unchanged). All additive, non-breaking, one-line edits; verified by a compile-time test in Phase 0.
- **A10 — Non-goals enforced by evidence**: no provider may be built on Google Programmable Search JSON API (closed to new customers; full API shutdown 2027-01-01 — ledger) or Bing Search API (retired 2025-08-11 — ledger). Brave Search / DataForSEO / serper.dev are PAID/BYOK-later — SPI hooks only, not built-ins (research §Seam 1+3 rows; I1).

Locked BYOK env-var names (**R5, scheme `SEOLITE_<PROVIDER>_KEY`**; config may override the NAME, never embed a value):
`SEOLITE_PSI_KEY`, `SEOLITE_CRUX_KEY`, `SEOLITE_OPR_KEY`.

Pacing override rule: config may override `rpm`/`burst` per provider; `resolvePacing` clamps them so `burst + rpm ≤ documentedLimit` whenever a documented limit exists (mechanism + test TC-REG-6). Providers without a documented limit (suggest, ddg) apply overrides as configured (defaults already conservative).

Error semantics summary (typed, provider name always attached): key absent where required → `not_configured`; 429 → `rate_limited` (+`retryAfterMs` from Retry-After); HTTP 5xx → `upstream_error` (retryable class — the core Fetcher has already exhausted its bounded retries); CAPTCHA/bot-block/other 4xx from gray endpoints → `blocked`; malformed JSON/HTML → `parse_error`; fetch-layer timeout/abort (typed) → `timeout`; stale local Tranco list → `stale_cache`; Tranco first run with all list dates 404 → `upstream_error`; CrUX "no data" → `null` (not an error); OPR per-domain non-quota error → that domain's signals omitted; Tranco/authority absence → `[]` (never zero-fill, never `value: undefined`).

## 4. Bounding assumptions (conservative defaults, recorded for autonomous mode)

- **BA1** Pacing policy per provider (GCRA worst-case rolling 60 s window = rate + burst): crux 140+10=150 (= documented 150, never above), opr 50+10=60 (= documented 60, never above), wikipedia rate 60/min = 0.30× documented 200 (worst window 70 with burst 10 = 0.35×), PSI keyed rate 60/min = 0.25× documented 240 (worst 70 = 0.29×), PSI keyless 6+1=7, suggest 30+5=35 (undocumented limit), ddg paced 6/min with burst 1 → worst 7 (undocumented limit). Overrides are clamped to keep worst-case ≤ documented limit (TC-REG-6).
- **BA2** Cache TTLs are the defaults in the matrix, configurable per provider via config (e.g. `tranco.refreshDays`); cache is a providers-local `CacheStore` port with an in-memory default — surfaces may inject a file-backed store later (core defines no cache contract).
- **BA3** Tranco: parse the first `maxRows` (default 100,000) rows of the published daily CSV (`download_path` from `GET https://tranco-list.eu/api/lists/date/{date}`); if today's list is unpublished, walk back up to 3 days; first run with all 4 dates 404 → typed `upstream_error`; serve cached up to 14 days (refresh failure at >14d → `stale_cache`); domains outside the top-N → omitted (`[]`), never a zero rank.
- **BA4** wikipedia-demand: `en.wikipedia` only in v1; demand = sum of trailing-28-day daily pageviews ending today−2d (data lag); no matching article → `[]` (omitted, I3); output explicitly labeled "demand proxy, not search volume".
- **BA5** pagespeed: keyless trial calls allowed only when `automated` is false (single interactive reports); batch/CI/MCP callers pass `automated: true` and therefore require the key; keyed and trial results never share cache entries (mode is part of the cache key).
- **BA6** NotConfigured is expressed as a typed error (code `not_configured`) under the locked SPI signatures (no result-union change to core); the engine/surface layer catches it and renders "not configured" — that catch IS the I1 "skip with explicit result". CrUX `null` is reserved for "API has no record" so the two meanings never collide.
- **BA7** `fcn` in the locked PageSpeedReport model is interpreted as First Contentful Paint (PSI audit `first-contentful-paint`).
- **BA8** Open PageRank request shape: per-domain GET `https://openpagerank.com/api/v1.0/getPageRank?domains[0]=<domain>` (the API's documented bulk param used with a single element, because the locked SPI `authority(domain: string, o)` handles ONE domain) with `Authorization: Bearer <key>`; response per-domain fields parsed as `page_rank_decimal` (fallback `page_rank_integer`) and `rank`; absent/non-finite values or per-domain errors → that domain's signals omitted (I3). The documented 100-domain bulk form is a future caller-side coalescing optimization, out of v1 scope.
- **BA9** ddg-serp is Node-only (cheerio per ARCHITECTURE "Node-side only"; the Worker parses no HTML per I6/R7): a `createWorkerSafeProviders(...)` export wires all providers except `ddg-serp`.
- **BA10** All fixtures are static, hand-written from the documented/observed API shapes recorded in research — no test fetches anything live, ever.
- **BA11** Unicode/IDN domains are lowercased and scheme/path-stripped before Tranco/OPR lookup; full IDNA punycode conversion is out of scope for v1 (documented limitation, consistent with research I15 bounding).
- **BA12** Core opts types (`IdeasOpts`, `SearchOpts`, report/crux/authority opts) are assumed minimal (`lang?`, `limit?`, `strategy?`, `formFactor?`, `automated?`, `scope?`); normalization/adaptation is confined to `src/opts-bridge.ts` (scheduled in Phase 1).
